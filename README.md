# 🌾 KrishiSahay – AI-Powered Agricultural Query Resolution System

KrishiSahay is an AI-powered agricultural assistance platform developed during the **GENAI-FORGE Hackathon**. It is designed to help farmers get quick and accessible solutions to common agricultural queries through a simple and user-friendly web interface.

## 🚀 Features

- 🤖 AI-powered agricultural query resolution
- 🌱 Assistance with farming-related questions
- 🌦️ Weather-related information
- 🧪 Fertilizer and crop-related recommendations
- 💻 Simple and farmer-friendly web interface
- ⚡ Flask-based backend for processing user requests

## 🛠️ Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **APIs:** AI / Weather APIs
- **Version Control:** Git & GitHub
